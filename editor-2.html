Copy Files for GitHub

How to update GitHub: 1. Click Copy on a file below  →  2. Go to your GitHub repo  →  3. Click the filename  →  4. Click the ✏️ pencil (Edit) button  →  5. Select all (Ctrl+A / Cmd+A)  →  6. Paste (Ctrl+V / Cmd+V)  →  7. Click Commit changes. Repeat for each file.
